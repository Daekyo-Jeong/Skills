## 시그니처 6 — 하나라도 빠지면 다른 사람

1. 가르마 없이 뒤로 넘긴 **웨이브 장발** (목덜미까지)
2. **얇은 사각 메탈 안경** (가로로 긴 사각, 모서리만 살짝 둥글게)
3. 양끝이 입꼬리 아래로 처지는 **팔자 콧수염**
4. 아래로 뾰족한 **삼각 턱수염** (진한 채움)
5. 로고 없는 **무지 반팔 크루넥 티**
6. 보이는 귓불에 걸린 **작은 링귀걸이** (가는 메탈 후프, 연필 한두 획)

## 부위별

- **헤어**: 앞머리를 이마 위로 크게 넘긴 볼륨, 가운데 살짝 갈라짐. 굵은 S자 결 3–5가닥으로 덩어리 표현(한 올씩 그리지 않음). 끝은 바깥으로 말림.
- **옆머리·귀**: 귀가 반쯤 드러남. 귀 뒤 안쪽 머리는 솔리드 연필 채움. 귀는 C자 + 안쪽 짧은 곡선 2개. 귓불에 귓불만 한 작은 링귀걸이(가는 원 한두 획). 보이는 귀마다 단다. 다른 장신구 없음.
- **안경·눈**: 렌즈가 눈썹 바로 아래까지 올라옴, 다리가 귀로 이어짐. 미간 주름 2–3줄, 짧고 진한 눈썹. 기본 눈은 아래로 휜 감은 눈 곡선.
- **수염**: 콧수염은 가운데가 얇음. 아랫입술 밑 작은 패치. 턱수염은 삼각형 진한 채움 + 거친 끝. 볼·구레나룻 수염 없음.
- **코·입**: 넓은 콧망울 + 콧구멍 두 점, 콧대 선 거의 생략. 다문 작은 입, 이 안 보임.
- **얼굴형·체형**: 둥글고 넓은 얼굴, 부드러운 이중 턱 느낌. 짧은 목, 둥근 어깨. 몸은 머리보다 단순하게.

## 선 스타일

- 4B 연필 느낌의 중간 굵기 단일 선. 한 번에 긋고 가끔 끊김. 스케치 겹선·밑그림 없음.
- 진한 채움은 **딱 세 군데**: 귀 뒤 옆머리, 턱수염, 몸 한쪽 외곽(소매 아래·옆구리 그림자). 같은 방향 빽빽한 사선 결.
- 회색 톤 면·블렌딩·문지른 음영 없음. 색 없음.
- 효과선(김, 반짝임)도 같은 연필 선으로 3줄 이내.

## 표정 · 포즈

감정은 크게, 얼굴 근육은 작게. 눈썹·미간·고개 각도로만 과장하고 입은 다문다. **예외: 웃음(폭소·멋쩍음)과 울음(오열)만 입을 벌린다.** 기준 그림은 `assets/expression-sheet.jpg`.

| 표정 | 묘사 |
|---|---|
| **음미 (기본)** | 눈 감고 미간 주름, 턱 들기, 입 꾹 |
| 심사 | 한쪽 눈썹 올리고 안경 너머로 내려다봄 |
| 몰입 | 고개 숙여 집중, 눈 가늘게 |
| 체념 | 처진 눈썹, 먼 산, 어깨 내려감 |
| 확신 | 눈 뜨고 정면, 입꼬리 한쪽만 아주 살짝 |
| 무표정 | 눈 뜨고 눈썹 평평, 입은 일자. 감정 없음(찌푸리지 않음) |
| 미소 | 입 다문 채 볼이 올라가고 눈이 초승달 |
| 폭소 *(입 벌림)* | 눈 질끈 감아 호, 입 크게 벌려 웃음, 고개 뒤로 |
| 멋쩍음 *(입 벌림)* | 머쓱하게 웃으며 뒷머리 긁기, 땀방울 하나 |
| 글썽 | 눈썹 가운데가 올라가고 눈물 맺힘, 입술 떨림(다문 입), 눈물 한 줄 |
| 오열 *(입 벌림)* | 눈 감고 양 볼로 눈물 줄줄, 입 벌려 엉엉 |

- 프레이밍: 3:4 세로, 상반신 바스트업, 3/4 정면, 턱 살짝 든 각도. 여백 35% 이상.
- 소품은 한 장에 하나, 얼굴 옆 높이. 시그니처 제스처: 가슴에 손 얹기, 소품을 손가락으로 집어 들기.
- 손은 크고 뭉툭하게. 배경·가구·다른 인물 없음.

## Do / Don't

Do: 시그니처 6 전부 / 흑연 단색 / 채움 세 군데(윗머리는 채우지 않음) / 입 다문 deadpan(웃음·울음만 예외) / 소품 하나 (+ 선택 캡션) / 3:4 바스트업

Don't: 링귀걸이 빠짐·큰 귀걸이·다른 장신구 / 둥근 안경·뿔테 / 짧은 머리·묶은 머리(맨번은 dkdk-walrus 전용) / 수염 없음·풀 수염 / 컬러·회색 블렌딩·매끈한 디지털 선 / 큰 눈·반짝이는 눈 / 웃음·울음이 아닌 장면에서 벌린 입 / 윗머리 전체를 진하게 채우기 / 엄니·지느러미 등 바다코끼리 요소 / 배경·말풍선·좌상단 제목
