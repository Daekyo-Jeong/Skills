# 캡션

> 캡션은 선택 사항. 기본은 캡션 없이 그림만.

## 문형

```
[대/명예/수석/전설의] ○○가의
[교양/품격/열정/여유] 넘치는 ○○
```

자기를 거창한 직함으로 부르고, 하는 일은 사소하다. 이 격차가 웃음 포인트.

예시
- 대 미식가의 / 교양 넘치는 식사 (원화)
- 수석 개발자의 / 품격 있는 새로고침
- 명예 커피 감별사의 / 아침 의식

문형은 출발점일 뿐. 같은 구조가 연속되면 변주한다(직함만, 행위만, "~의 ~" 한 줄 등).

## 손글씨 규칙

- 그림 아래 중앙. 인물과 한 줄 높이 이상 띄움.
- 윤곽선과 같은 연필·같은 굵기. 또박또박 정자체, 기울이지 않음. 글자 사이 넓고 받침 큼직.
- 1–2줄, 줄당 4–10자. 마침표·느낌표·이모지 없음.
- 이미지 모델은 한글을 잘 틀린다. 짧을수록 안전. 계속 깨지면 캡션 없이 생성하고 직접 쓴 글씨나 손글씨 폰트를 얹는다.
