# QA 체크리스트

## 필수 통과

- 3:4 세로, 흰 종이 배경, 색 없음.
- 시그니처 5 전부: 웨이브 장발 / 얇은 사각 메탈 안경 / 팔자 콧수염 / 삼각 턱수염 / 무지 반팔티.
- 원화와 같은 사람으로 보인다 (얼굴형, 코, 귀, 미간).
- 선이 연필 단일 굵기, 진한 채움은 세 군데 이내.
- 입 다문 deadpan. 소품 하나.
- (캡션을 넣었다면) 아래 중앙, 오타 없음. 캡션 없이 요청했다면 글자가 하나도 없음.
- 여백 35% 이상, 배경·말풍선·다른 인물 없음.

## 실패 신호 → 대응

| 신호 | 대응 |
|---|---|
| 안경이 둥글거나 뿔테 | 아이덴티티 보정 프롬프트로 부분 수정 |
| 머리가 짧아지거나 묶임 | 재생성 (hair 문장 강조) |
| 수염 빠짐 / 풀 수염 | 부분 수정 |
| 회색 그라데이션·디지털 선 | "no gray shading, pencil only" 강조 재생성 |
| 웃는 입·큰 눈·귀여움 | "deadpan, closed mouth, not cute" 강조 재생성 |
| 원화 포즈·치킨 복제 | 장면 묘사를 더 구체화해 재생성 |
| 캡션 오타 | 캡션 수정 프롬프트 → 계속 깨지면 캡션 줄이기 또는 후처리 |
