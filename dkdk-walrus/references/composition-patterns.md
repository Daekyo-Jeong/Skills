# 구도 패턴과 은유 발명 규칙

## 기본 구조 유형

하나만 고른다. 여러 개 섞지 말 것.

### 워크플로

적합: 입력 → 처리 → 출력, 콘텐츠 생산, AI 워크플로, 자동화 체인.

그리는 법: 왼쪽 입력, 가운데 dkdk 또는 괴상한 기계가 처리, 오른쪽 출력. 주황 화살표로 주 흐름.

### 시스템 부분도

적합: 정보 소스, 필터, 데이터베이스, 렌더러, agent 시스템의 일부.

그리는 법: 핵심 모듈 3-5개만 그리고, dkdk가 그중 한 군데의 핵심 동작에 참여.

### 전후 대비

적합: 혼란/정돈, 수동/자동, 흩어짐/모임, 불안/안정.

그리는 법: 왼쪽 혼란, 오른쪽 안정, 가운데 주황 화살표. 캐릭터는 좀 더 과장 가능.

### 상태 변화

적합: 사용자 페인포인트, 창작자 상태, 도구 과다, 정보 불안, 막힘→풀림.

그리는 법: 작은 상태 2-4개, 상태마다 짧은 라벨 하나.

### 개념 은유

적합: 콘텐츠 공장, 정보 창고, 머릿속 블랙박스, 워크플로 기계, 자동 리포트.

그리는 법: 큰 괴상한 물건이나 기계 하나, 입력 약간, 출력 하나. 기억에 남는 포인트가 있어야 함.

### 방법 계층

적합: 방법론 프레임, 시스템 레이어, 능력 스택, 콘텐츠 시스템 계층.

그리는 법: 상자를 층층이. 정식 피라미드 금지. dkdk는 옆에서 쌓거나 나르는 중.

### 지도 경로

적합: 아이디어→출시, 사용자 여정, 인계 경로, 학습 루트.

그리는 법: 구불구불한 길 하나, 노드는 조금만, dkdk가 줄을 끌거나 걷는 중.

### 미니 만화 분할

적합: 실패→성공, 실제 과정, 자조 개그, 사용 전후 변화.

그리는 법: 작은 장면 2-4컷, 컷마다 동작 하나만.

## 은유 발명 3단계

매번 지금 글에서 새로 발명한다. 옛 그림을 재사용하지 않는다.

1. 추상 개념을 물리 동작 하나로 치환: 끼임, 새어나감, 무거워짐, 분류, 침전, 발효, 문 열기, 접기, 포장 풀기, 역류.
2. 시스템 구조를 로테크 물건 하나로 치환: 고장난 기계, 종이상자, 서랍, 수도관, 우체통, 괴상한 계기판, 저울, 우물, 사다리, 이상한 작업대.
3. dkdk가 그 동작을 수행: 옆에 서 있는 게 아니라 — 기계에 끼거나, 줄을 잘못 당기거나, 문을 지키거나, 나르거나, 수선하거나, 무게를 재거나, 사다리를 붙잡거나, 기록하거나, 뭔가를 괴상한 장치에 밀어넣는 중.

### 물건 풀

- 종이상자, 서랍, 낡은 기계, 깔때기, 저울, 우체통, 문, 우물, 사다리, 수도관, 실타래, 수문, 회전판, 블랙박스, 펀칭기, 반죽기, 빨랫줄, 괴상한 작업대.
- 한 장에 1-2개만. 쌓아놓지 말 것.

### 동작 풀

- 당기기, 메기, 밀어넣기, 건지기, 누르기, 재기, 꿰매기, 자르기, 비틀기, 지키기, 밀기, 받기, 뜯기, 표시하기, 회수하기.
- 동작은 핵심 의미에 봉사해야 한다. 엉뚱함을 위한 엉뚱함 금지.

## 복제 금지 규칙

기준 이미지(모델시트)는 캐릭터 아이덴티티 캘리브레이션 전용이다 — 선 밀도, 여백, 색 절제, dkdk의 분위기.

사용자가 "이 그림처럼 / 이 구도 복제해줘"라고 명시하지 않는 한, 이전에 만든 구도를 그대로 재사용하지 말 것. 같은 주제라도 은유를 갈아끼운다. 예: "인계 경로"라고 꼭 길을 그릴 필요 없다 — dkdk가 콘텐츠 꼬리를 문손잡이에 묶는 그림일 수도 있다. "하나로 여러 용도"도 꼭 생선을 자를 필요 없다 — 종이 뭉치를 여러 모양으로 눌러 찍는 그림일 수 있다.
